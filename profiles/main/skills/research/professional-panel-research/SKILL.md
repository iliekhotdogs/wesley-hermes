# Professional Panel Research

- Fetch the full organizer roster and all biographies before assigning research. Resolve full names from body text rather than abbreviated headings; preserve exact organizer affiliations and distinguish them from employment.
- Delegate non-overlapping subsets to installed research specialists. Discover their actual capabilities first. Read-only researchers should return source-backed findings in task comments; main owns citation-ledger execution, file creation and native artifact delivery when those operations are denied. Do not make a forbidden write the researcher's completion gate.
- Match individual LinkedIn identities against employer plus geography, education, distinctive credentials or career history. Never guess handles or substitute companies/directories/search pages. Clearly distinguish indexed-result evidence from full-profile access; an inaccessible LinkedIn body is a disclosure, not automatically a blocker.
- When search finds only public LinkedIn posts, main can retrieve their public HTML and inspect author/View Profile anchors for the exact profile URL. Never infer a profile mechanically from a post slug. Use bounded read-only HTTP without authentication workarounds.
- Attribute organizer-only facts, check employer bios where possible, and distinguish historical roles/headcounts from current facts. Preserve degree/title discrepancies rather than silently harmonizing them.
- Give every person an observed LinkedIn outcome, meaningful professional facts, an explicitly inferred preparation takeaway and optional practice question. Never infer actual judging preferences or the official rubric from a career history.
- On MAIN_REQUIRED, perform the exact denied prerequisite as main and supply its verified result. Resume the same task at most once after a concrete correction. If the boundary recurs or useful findings are already handed off, finish the artifact yourself without expanding specialist permissions or recreating cards.
- Check for an already-active recovery worker before taking over, and coordinate with it through the existing source card to avoid duplicate collection or delivery.
- Produce one consolidated brief with a task-local citation ledger. Programmatically verify roster coverage, unique identities and matched/unmatched totals; render the source list mechanically and run citation validation. Recommendations and practice questions must be labeled inferences.
- Use native lifecycle completion after verification. For authorized main takeover of a triage source, use the installed scoped kanban_recovery.py settle helper; never settle an active worker. Preserve useful findings and deliver the real consolidated file to the originating chat rather than merely giving a local path.
